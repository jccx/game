# 疾风卡丁

原创的卡丁车竞速：三条赛道（森林环道、沙漠峡谷、冰雪港湾），每场三圈，你和七个电脑车手比。

## 操作

- **手机**：自动给油。左下摇杆左右转向；右下大键“漂移”（按住），旁边是“氮气”“道具”“刹车”。
- **电脑**：A/D 或方向键转向，Shift 或空格漂移，J 氮气，K 道具，S 刹车，Esc 设置。
- **漂移**：过弯时按住漂移并打方向，车会侧滑；车尾火花从白变蓝、橙、紫，松开时按颜色给一段加速。
  漂移同时会攒屏幕下方的氮气槽，攒满得一瓶氮气（最多存两瓶）。
- **道具**：压过彩色问号箱得到一个——香蕉皮（丢在身后）、导弹（打前一名）、护盾（6 秒不怕道具）、氮气。
  名次越靠后越容易抽到导弹和氮气。
- **无敌**（右上，作弊开关）：打开后不怕道具、蹭墙不掉速。
- 每条赛道的最快单圈会记在本机。

## 代码结构（`kart/js/`）

| 文件 | 作用 |
|---|---|
| `config.js` | 数值：车速、漂移、氮气、道具权重、难度。**调手感改这里** |
| `tracks.js` | 赛道数据：每条赛道是一圈控制点加宽度和主题，程序自动连成平滑曲线。**改赛道、加赛道改这里** |
| `race.js` | 比赛规则：卡丁车物理、道具、电脑车手、圈数和名次。不含画面，可脱离浏览器跑 |
| `render.js` | 赛道和场景的生成、卡丁车模型、特效、追尾镜头 |
| `hud.js` | 开局菜单、比赛界面和输入、结算 |
| `main.js` | 入口 |

## 常见改动怎么做

- **加一条赛道**：在 `tracks.js` 的 `TRACKS` 里加一项（控制点按顺序围成一圈，起点是第一个点）。
  加完跑 `node test/kart-sim.mjs`，它会检查路段有没有互相重叠、弯是不是太急、电脑车能不能跑完。
  要新主题就在 `render.js` 的 `THEMES` 和景物生成里加一种。
- **加一种道具**：`config.js` 的 `ITEMS` 加一项，`race.js` 的 `useItem()` 里写效果，`rollItem()` 里给权重。

## 调试

地址栏参数：`?auto=1&track=forest&diff=1` 跳过菜单直接开赛，加 `&bots=1` 让自己的车也由电脑开。
控制台里 `__kart.race` 是比赛对象，`__kart.loop.fastForward(10)` 快进 10 秒。
