# 豆兵大战

原创的回合制炮战：2 到 4 支豆子队，每队 2 到 4 个豆兵，在一张可以炸出坑的地形上轮流开火。算好角度、力度和风向，把对面的豆兵轰下地图，掉进水里直接出局。

## 操作

- **手机**：轮到你时，左下 ◀ ▶ 走路，跳可以跳上小坡，后翻是向后跳。右下大键“开火”按住拖动瞄准：拖的方向是发射方向，拖得越远力度越大，松手发射，拖回中心取消。开火前可以点“武器”换武器。
- **空袭和传送**：先点一下地图选位置（画面上出现黄色标记），再拖开火键发射。
- **电脑**：A/D 或方向键走，W 或空格跳，S 或 F 后翻，数字键 1~8 选武器，Enter 跳过回合，Esc 设置。
- **无敌**（右上，作弊开关）：打开后自己的豆兵挨炸不掉血，落水会回到上一个落脚点。
- 画面上拖动可以移动镜头看地图，右上“全景”可以看整张地图，滚轮可以缩放（电脑）。

## 武器

| 武器 | 效果 |
|---|---|
| 火箭筒 | 受风影响，撞到就炸 |
| 手雷 | 会弹跳，3 秒后爆炸，不受风影响 |
| 霰弹枪 | 一回合可以开两枪，直线命中 |
| 集束弹 | 爆炸后分裂成五颗小炸弹 |
| 空袭 | 点地图选位置，五枚导弹从天而降 |
| 炸药 | 放在脚下，4 秒后大爆炸，放完快跑 |
| 重拳 | 把贴身的敌人打飞 |
| 传送 | 点地图上的空地，瞬间移动过去 |

每回合限时 30 秒，超时自动跳过。炮弹炸完、所有豆兵站稳之后换下一队。

## 代码结构（`artillery/js/`）

| 文件 | 作用 |
|---|---|
| `config.js` | 数值：物理、回合规则、武器表、队伍、难度、地形主题。**调平衡改这里** |
| `game.js` | 对局规则：可破坏的地形、豆兵物理、武器、回合流程、电脑 AI。不含画面，可脱离浏览器跑 |
| `render.js` | Canvas 2D 画面：地形离屏画布（爆炸后只重画受影响的区域）、天空、云、水面、豆兵、炮弹、粒子、瞄准预览线、镜头 |
| `hud.js` | 开局菜单、回合界面和输入、武器面板、结算 |
| `main.js` | 入口 |

## 常见改动怎么做

- **加一种武器**：`config.js` 的 `WEAPONS` 加一项，`game.js` 的 `fire()` 里写效果（`kind` 已有的 shell / bomb / gun / strike / drop / melee / move 七种里挑一个，多数新武器不用改逻辑）。
- **改地形**：`config.js` 的 `THEMES` 加一种主题（天空、地形、水面的配色）；地形起伏在 `game.js` 的 `Terrain` 里生成。
- **调电脑强度**：`config.js` 的 `DIFFICULTY`（瞄准误差、力度误差、思考时间）。

## 调试

地址栏参数：`?auto=1` 跳过菜单直接开局，加 `&bots=1` 让自己的队也由电脑开，加 `&teams=3&size=2&diff=0&theme=1&seed=123` 指定队伍数、人数、难度、地形和地图种子。
控制台里 `__artillery.game` 是对局对象，`__artillery.loop.fastForward(10)` 快进 10 秒。
