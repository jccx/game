# 裂谷争锋

3D 斜俯视的英雄对战。三种模式开局前选：5v5 三路、3v3 单路、1v1。五个原创英雄，你操控一个，其余全部由电脑控制。

## 操作

- **手机**：左下摇杆移动；右下大键普攻（点一下会持续攻击当前目标），旁边两个小键是“补兵”“推塔”；
  三个技能键按住拖动可以瞄准，松手释放，拖到右上“取消”处松手则不放；技能键上出现金色“+”时点它加点
  （六秒不加会自动加）；下方是回城、恢复、闪现；左上小地图下面是快捷购买。
- **作弊按钮**：屏幕顶部偏右的“无敌”，是个开关：点一下打开（不掉血、不吃控制，身上有金色光罩），再点一下关闭。它右边依次是商店和金币。
- **电脑**：WASD 移动，J / 空格 / 鼠标左键普攻，Q E R 技能（朝鼠标位置），1 2 3 加点，B 回城，F 闪现，G 恢复，P 商店，Esc 设置。

## 代码结构（`moba/js/`）

逻辑和画面完全分开：`game.js` 一侧不碰任何画面代码，可以脱离浏览器跑整局（`test/moba-sim.mjs` 就是这么测的）。

| 文件 | 作用 |
|---|---|
| `config.js` | 全部数值：小兵、塔、野怪、经济、英雄通用规则、难度、各模式节奏。**调平衡改这里** |
| `maps.js` | 三张地图的数据：兵线、塔位、墙、营地。场景和碰撞都由它生成，**改地图改这里** |
| `world.js` | 地形碰撞和寻路（A*） |
| `entities.js` | 单位逻辑：英雄、小兵、防御塔、水晶、野怪 |
| `heroes/` | 每个英雄一个文件（属性、被动、三个技能），`index.js` 是登记表 |
| `items.js` | 装备表和各英雄的推荐出装 |
| `ai.js` | 电脑英雄的 AI（定目标 + 走位出手） |
| `game.js` | 对局规则：出兵、伤害、击杀、投射物、胜负 |
| `render/scene.js` | 地面贴图、河水、墙和树、灯光（全部现场生成） |
| `render/models.js` | 英雄、小兵、塔、水晶、野怪的模型（用基本形体拼） |
| `render/fx.js` | 投射物、指示圈、冲击波、粒子、飘字、瞄准指示器 |
| `render/view.js` | 每帧把对局状态画出来：镜头、模型动作、血条 |
| `render/portrait.js` | 选人界面的英雄头像 |
| `hud.js` | 对局界面和玩家输入 |
| `menu.js` | 开局菜单 |
| `main.js` | 入口，把上面各模块接起来 |

## 常见改动怎么做

- **加一个英雄**：在 `heroes/` 里照着现有文件写一个，在 `heroes/index.js` 登记；在 `render/models.js` 加模型；
  在 `items.js` 的 `BUILDS` 里给它配推荐出装。技能的图标名对应 `hud.js` 里的 `ICONS`。
- **加一件装备**：在 `items.js` 的 `ITEMS` 里加一行。
- **调难度**：`config.js` 的 `DIFFICULTY`。
- **调一局的长短**：`config.js` 的 `PACE`（小兵成长速度、塔的血量）。

## 调试

地址栏参数：`?auto=1&mode=5v5&hero=liefeng&diff=1` 跳过菜单直接开局；加 `&bots=1` 让自己的英雄也由电脑控制（观战）；
`&q=0/1/2` 强制画质档位。控制台里 `__moba.game` 是对局对象，`__moba.loop.fastForward(60)` 快进 60 秒。
